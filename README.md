# COS10005 — Web Development Coursework

This repository holds coursework for **COS10005 (Web Development)** — HTML/CSS/JS labs, class examples, and an assignment. Each folder is self-contained: open any `.html` file in a browser (no build or server needed).

| Folder | What's in it |
|---|---|
| `week02/` | Week 2 class examples: notes page (`index.html`), Tom & Jerry image, and a sample form (`sample_form.html`). |
| `week08/` | Week 8 JavaScript examples: `if/else`, `switch`, `array`, `demo`, plus a picture slideshow (HTML + JS). |
| `Lab/Week02_Lab_files-1-1/` | Week 2 lab handout files (unit outline in HTML/PDF/TXT/DOCX). |
| `Lab/lab01/` | Lab 1 page (`index.html`, `style.css`). |
| `Lab/lab03/` | Lab 3 survey pages (`survey01`–`survey05.html` + `styles.css`). |
| `Lab/lab04/` | Lab 4 pages: `home.html`, `about.html`, `wis.html` (`style.css`). |
| `Lab/lab05/` | Lab 5 survey site: `surveyhome.html`, `about.html`, `takesurvey.html` with `css/` (small/surveyhome stylesheets) and images. |
| `Lab/lab06/` | Lab 6 registration form (`regform.html`, `css/` with mobile/desktop/style stylesheets). |
| `Lab/Lab07/` | Lab 7 registration form with tooltip (`regform2.html`, `tooltip.js/.css`). |
| `Lab/lab08/` | Lab 8 registration form with modal popup (`regform2.html`, `modal.js/.css`, `desktop.css`). |
| `Lab/lab09/` | Lab 9 registration form with validation logic (`regform2.html`, `validation.js`, desktop stylesheet). |
| `Lab/lab10/` | Lab 10 registration form: validation + error popup + Section A/B collapse (`regform2.html`, `validation.js`, `modal.css`, `jquery.min.js`). See `Lab/lab10/README.md` for details. |
| `Class/` | Class-level files. |
| `104992813_assign1/` | Assignment 1 site: home/suburb/activities/food/animations pages, `style/` (mobile/desktop CSS), and `images/`. |
| `lab2.1.html`, `lab01.zip` | Standalone lab files. |

## Technologies
Plain HTML, CSS (Flexbox, responsive mobile/desktop stylesheets), and JavaScript (including jQuery in Lab 10). No package manager or build step — just open the pages.
